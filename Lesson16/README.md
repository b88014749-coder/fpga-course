2. Frequency meter

Four 32-bit registers.

Offset	Register	Access	    Purpose
0x00	WINDOW      Read/write	Number of clock cycles in the measurement window
0x04	CTRL        Write       Writing 1 to bit 0 starts a measurement, reading will always return 0
0x08	COUNT       Read        Number of rising edges detected during the last completed measurement
0x0C	STATUS      Read        Bit 0 is 1 when the measurement is complete; otherwise, 0

Testbench test cases:
1. Input period is 100 clock cycles, measurement window = 1000 clock cycles. The expected COUNT is 10.
2. Input period is 40 clock cycles, measurement window = 2000 clock cycles. The expected COUNT is 50.
3. Input period = 100 clock cycles, measurement window = 250 clock cycles.
The expected COUNT is either 2 or 3. The measurement window is 2.5 times the input signal's period,
so the number of rising edges within the window depends on the relative phase between the input
signal and the measurement window. Since the input signal is asynchronous to the system clock,
synchronization also affects the precise timing at which rising edges are detected. Both results are valid.
